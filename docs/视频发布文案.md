## 二、简介（整段复制，B 站上限 2000 字）

```
智练 SmartFit —— AI 驱动的个人健康 / 运动管理平台。2026 第九届传智杯全国大学生数智创新与 AI 应用大赛 · AI WEB 网页开发挑战赛参赛作品，队伍：智护三角。

它不是「套壳 AI 聊天页」，而是把 AI 训练成一条可解释、可校验、可降级的工程流水线。

【这个视频看什么】
00:00 开场：我们想解决的三件事
00:25 数据总览：60 天身体数据 + 打卡 + AI 建议一屏看完
01:05 重点一 · AI 健身计划：勾选「膝关节不适」当硬约束，7 秒生成 4 周分化计划，并展示「生成过程」时间线（各阶段耗时 / 实际引用的知识库条目 / 校验与审核结论）
02:45 运动打卡 + 身体数据：热量由服务端 MET 公式算，结果回显计算依据
03:25 重点二 · AI 教练：SSE 流式，首字 <1 秒；回答下方直接标出命中的本地知识库条目；右侧原文展示「注入给模型的数据快照」
04:40 重点三 · 拍照识热量：一张饭菜照片 → 食物 / 克数 / 热量，每项标注「库内精确」还是「模型估算」
05:40 重点四 · 设备同步：蓝牙心率带直连 + 手环导出文件导入 + Apple「健康」导出 zip 浏览器内解析 + 免登录同步令牌
06:30 健康饮食 + 数据可视化：AI 一日配餐带热量偏差校验；6 类图表
07:05 社区 + 工程底色

【AI 技术亮点】
· RAG 检索增强：自实现中文 BM25（单字 + bigram）+ 结构化过滤 + MMR 去重 + 口语查询扩展，零依赖、毫秒级、每条引用都可点开验证
· 结构化输出校验与修复：JSON Schema 校验 → 自动修复重试 → 仍失败则降级
· 安全审核 Agent：伤病 / 慢病 → 禁忌动作映射为纯规则代码，移除动作时给出自然语言理由（不依赖模型自觉）
· 三层降级：大模型 → 修复重试 → 本地规则引擎 / 检索式问答，没网没 Key 也能完整演示
· 多模态双源交叉校验：视觉模型与本地食物库互相校验，热量相差 >3 倍判为误匹配并弃用库值、界面标注来源
· 工程取舍：只让模型生成第一周模板，后三周按渐进超负荷规则展开——让模型做决策，让代码做重复劳动（实测 19 秒且会截断 → 7 秒一次通过）
· 全链路可观测：每次 AI 调用的场景 / 耗时 / 缓存 / 降级 / 重试 / RAG 命中全部落库

【技术栈】
前端 Vue 3.5 + Vite 6 + Element Plus + ECharts；后端 Node.js 22 + Express + node:sqlite（零外部数据库）+ Zod + JWT；部署 Docker + Render。
```
