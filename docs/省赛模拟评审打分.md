## 四、要拿前三，还差什么（按性价比排序）

1. **真实集再扩到 40~50 张**（含早餐、夜宵、学校食堂套餐）——样本量越大，"不是挑数据"越不可反驳；
2. **补 3~5 张失败案例的对比图**：同一张照片，我们 vs 通用模型的说法差异，直观展示「以库为准」的价值；
3. **加一段 60 秒的 RAG 消融现场录像**：把 `curl -N` 的双答案对比录进视频，比 PPT 更有说服力；
4. **检索升级为 BM25 + 向量 RRF**（需 embedding 服务），把 Recall@1 从 81.5% 推到 90%+，这是技术深度的最大增量；
5. **加 GitHub Actions**：push 即跑 `verify-submission` + `test-food-match` + `eval-rag`，把"工程质量"从口头变成流水线。
