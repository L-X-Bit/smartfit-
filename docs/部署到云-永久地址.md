# 部署到云 —— 拿到一个「永久不变」的网址

> 目标：把**一个固定网址**发给别人，对方用 4G / 5G 或任何网络都能直接打开，而且**不需要你的电脑开着**。

---

## 先说清楚：为什么免费隧道做不到「永久固定」

| 方案 | 网址是否固定 | 需要账号 | 打开体验 | 结论 |
| --- | --- | --- | --- | --- |
| `localhost.run`（本项目默认） | ❌ 官方文档明确「域名会定期变化」防钓鱼 | 免费不用注册 | 干净，无拦截页 | 临时分享够用 |
| `pinggy`（备用线路） | ❌ 每次重连变域名，免费会话 60 分钟 | 不用 | 干净 | 兜底 |
| `serveo` | 可保留子域名（需登记 SSH key） | 需要 | ⚠ 免费版首访有「警告页」要手动点继续 | 不推荐 |
| `ngrok` 免费静态域名 | ✅ 固定 | 需要注册 | ⚠ 免费版首访有警告页 | 可选 |
| **云平台部署（本文）** | ✅ **固定，永不变** | 需要注册 | 干净 | **推荐** |

一句话：**要「发一次永久有效」，只能把应用部署到云平台（或买域名做自有隧道）。**
免费隧道的域名按设计会变，这不是配置问题。

---

## 推荐：Render.com 免费部署（本仓库已备好配置）

仓库根目录已包含 `Dockerfile`、`render.yaml`、`.dockerignore`，平台会按蓝图自动建服务。

### 步骤

1. **把代码推到 GitHub**（这是唯一的前置条件，也是比赛要求的一部分）

   ```bash
   # 在 GitHub 上新建一个空仓库（不要勾选 README），拿到地址后：
   git remote add origin https://github.com/<你的用户名>/smartfit.git
   git push -u origin main
   ```

2. 打开 <https://render.com> → 用 GitHub 账号登录（免费）

3. **New → Blueprint** → 选择刚推上去的仓库 → Render 会读到 `render.yaml` → **Apply**

4. 部署过程中在服务页填环境变量（`render.yaml` 里已标 `sync: false` 的那个）：

   | Key | 值 |
   | --- | --- |
   | `AI_API_KEY` | 你的 DeepSeek Key（**不要提交进仓库**） |
   | `AI_BASE_URL` / `AI_MODEL` / `AI_VISION_MODEL` | 蓝图里已预填，不用管 |

5. 等 3~5 分钟首次构建完成，你会得到一个固定域名，形如：

   ```
   https://smartfit-xxxx.onrender.com
   ```

   **这个网址永久不变**，直接复制发给别人即可；演示账号 `demo / 123456`。

### 免费套餐的真实限制（务必知道）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 15 分钟没人访问，第一次打开要等 30~60 秒 | 免费实例会休眠，被访问时唤醒 | 演示前自己先打开一次预热 |
| 重启后自己新增的数据没了 | 容器文件系统是临时的，SQLite 跟着重建 | 启动时会自动导入知识库 + 演示数据（所以内容还在）；要保数据就加 Persistent Disk，并把 `DB_FILE` 指到挂载路径 |
| 上传的图片重启后打不开 | 同上（`server/uploads` 在临时盘） | 演示用的帖子多是内置数据，影响很小 |

> 部署后请顺手确认：打开 `<域名>/api/health` 返回 `{"code":0,...}`，首页能看到登录页。

## 备选平台（同样是用现成的 Dockerfile）

| 平台 | 免费额度 | 说明 |
| --- | --- | --- |
| **Zeabur** | 有免费额度 | 国内访问速度较好，支持 Dockerfile 一键部署 |
| **Railway** | 有试用额度（需绑卡） | 部署体验最好，注意额度消耗 |
| **Fly.io** | 有免费额度 | 需要 `flyctl` 命令行，配置更灵活 |
| **Render** | 永久免费（会休眠） | 本文推荐，零命令行 |

国内平台（阿里云函数计算 / 腾讯云 CloudBase）也能跑，但都需要实名与备案域名才能给外部访问，比赛场景不如上面几个快。

## 部署之后：本地演示照旧

云上那份是给别人看 / 给评委点开的；**录视频、现场答辩仍然用本地那份**（双击「启动智练SmartFit」），
本地没有休眠、没有带宽限制、AI 响应也更快。

两边的数据是**各自独立**的（本地 SQLite vs 云端 SQLite），演示时不要混着讲。
